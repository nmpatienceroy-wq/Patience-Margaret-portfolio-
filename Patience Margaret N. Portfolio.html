# About Me
I am a computer science student at **Uganda Christian University**.
I enjoy working with data from start to finish. I begin by
enumerating it, which means going through every record,
labelling it and counting what is there. Then I present the
results as charts so anyone can understand them quickly.
## What I do
- **Data enumeration**: listing every item in a dataset,
sorting each one into a category and counting them, so
every total can be checked.
- **Data visualization**: choosing the right chart for the
question and labelling it clearly so the main point is
easy to see.
